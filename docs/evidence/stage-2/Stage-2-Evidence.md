# Stage 2 – Progress Evidence

## Project

SimOS – Multi-Core Operating System Simulator

## Stage

Stage 2 – Project Requirements & Development Plan

## Evidence 1 – Requirements Documentation

The functional and non-functional requirements of the SimOS project have been documented.

The requirements define the expected system behaviour, performance, reliability, concurrency, maintainability, portability, usability, version control, and documentation requirements.

## Evidence 2 – Project Modules

The major project modules have been identified:

- Process Module
- Scheduler Module
- CPU/Core Module
- Resource Manager Module
- Synchronization Module
- Main Simulation Module

## Evidence 3 – Project Features

The planned project features include:

- Multi-core CPU simulation
- Multi-threaded process execution
- Process ready queue
- Process scheduling
- Process state tracking
- Shared resource management
- Resource allocation and release
- Thread synchronization
- Process re-queuing
- Process termination
- Terminal-based simulation output
- Linux-based execution

## Evidence 4 – Development Plan

A six-stage development plan has been prepared covering:

1. Project Introduction
2. Requirements & Development Plan
3. System Design & Architecture
4. Initial Implementation & Prototype
5. Testing, Integration & Improvement
6. Final Implementation & Presentation

## Evidence 5 – Development Environment

The planned development environment includes:

- Linux / Ubuntu
- C++17
- g++
- Make
- C++ Threads
- Mutex
- Queue
- Git
- GitHub

## Evidence 6 – Deliverables

The planned deliverables include:

- Project documentation
- C++ source code
- Header files
- Makefile
- Working executable
- UML diagrams
- System architecture diagram
- Testing documentation
- Git repository
- Final project report

## Evidence 7 – Version Control Plan

Git will be used throughout the project to maintain development history.

Meaningful commits will be created for major stages and implementation changes, and the project will be regularly pushed to GitHub.

## Stage 2 Completion Status

Stage 2 requirements, modules, features, deliverables, development plan, timeline, and version control strategy have been documented.
